# Statistics API

> Delivery totals, time series, provider / bounce breakdowns and metrics by domain, stream or tag.

Source: https://zapsmtp.com/docs/stats/

Counts for the window you ask for, limited to your plan’s log retention.

- [Totals](https://zapsmtp.com/docs/stats/stats/): GET
- [Time series](https://zapsmtp.com/docs/stats/stats-timeseries/): GET
- [Breakdown](https://zapsmtp.com/docs/stats/stats-breakdown/): GET
- [Metrics by domain, stream, tag or provider](https://zapsmtp.com/docs/stats/metrics/): GET
