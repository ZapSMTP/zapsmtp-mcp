# Logs & usage API

> Every API request with its bodies, and this month’s usage against your plan.

Source: https://zapsmtp.com/docs/logs/

Find out exactly what your code sent and what we answered. Every response’s `X-Request-Id` is the id of its log entry.

- [List logs](https://zapsmtp.com/docs/logs/list-logs/): GET
- [Retrieve a log](https://zapsmtp.com/docs/logs/get-log/): GET
- [Retrieve usage](https://zapsmtp.com/docs/logs/usage/): GET
