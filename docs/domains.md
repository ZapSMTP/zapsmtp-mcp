# Domains API

> Add and verify sending domains; tracking, reply tracking, brand and reputation.

Source: https://zapsmtp.com/docs/domains/

Add the domain you send from, publish the DNS records it returns (DKIM, SPF, DMARC) and verify it. Live keys can only send from verified domains.

- [List domains](https://zapsmtp.com/docs/domains/list-domains/): GET
- [Add a domain](https://zapsmtp.com/docs/domains/create-domain/): POST
- [Retrieve a domain](https://zapsmtp.com/docs/domains/get-domain/): GET
- [Verify a domain](https://zapsmtp.com/docs/domains/verify-domain/): POST
- [Update a domain](https://zapsmtp.com/docs/domains/update-domain/): PATCH
- [Domain reputation](https://zapsmtp.com/docs/domains/domain-reputation/): GET
- [DMARC reports](https://zapsmtp.com/docs/domains/domain-dmarc/): GET
- [Check reputation now](https://zapsmtp.com/docs/domains/check-domain-reputation/): POST
- [Retrieve brand settings](https://zapsmtp.com/docs/domains/get-brand/): GET
- [Update brand settings](https://zapsmtp.com/docs/domains/update-brand/): PUT
- [Delete a domain](https://zapsmtp.com/docs/domains/delete-domain/): DELETE
