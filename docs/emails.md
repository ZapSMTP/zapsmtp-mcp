# Emails API

> Send, schedule, batch and inspect email through the ZapSMTP API.

Source: https://zapsmtp.com/docs/emails/

Send one email or up to 100 in a batch, schedule them, and follow every recipient from acceptance to the remote server’s reply. Sending to `…@simulator.zapsmtp.com` with a test key runs the whole pipeline without delivering anything.

- [Send an email](https://zapsmtp.com/docs/emails/send-email/): POST
- [Send a batch](https://zapsmtp.com/docs/emails/send-batch/): POST
- [List emails](https://zapsmtp.com/docs/emails/list-emails/): GET
- [Retrieve an email](https://zapsmtp.com/docs/emails/get-email/): GET
- [Retrieve email content](https://zapsmtp.com/docs/emails/get-email-content/): GET
- [Reschedule an email](https://zapsmtp.com/docs/emails/reschedule-email/): PATCH
- [Cancel a scheduled email](https://zapsmtp.com/docs/emails/cancel-email/): POST
- [Spam-check a draft](https://zapsmtp.com/docs/emails/spam-check-draft/): POST
- [Spam-check a sent email](https://zapsmtp.com/docs/emails/spam-check-email/): POST
- [List attachments](https://zapsmtp.com/docs/emails/list-sent-attachments/): GET
- [Retrieve an attachment](https://zapsmtp.com/docs/emails/get-sent-attachment/): GET
- [Share an email](https://zapsmtp.com/docs/emails/share-email/): POST
