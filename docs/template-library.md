# Modules, images & timers API

> Saved modules, template images and countdown timers for the visual template editor.

Source: https://zapsmtp.com/docs/template-library/

What the visual editor shares across templates: modules (saved rows any template can insert), images hosted on a public URL, and countdown timer images. All of it works through the API too.

- [List modules](https://zapsmtp.com/docs/template-library/list-template-modules/): GET
- [Save a module](https://zapsmtp.com/docs/template-library/create-template-module/): POST
- [Retrieve a module](https://zapsmtp.com/docs/template-library/get-template-module/): GET
- [Update a module](https://zapsmtp.com/docs/template-library/update-template-module/): PATCH
- [Delete a module](https://zapsmtp.com/docs/template-library/delete-template-module/): DELETE
- [List images](https://zapsmtp.com/docs/template-library/list-template-assets/): GET
- [Upload an image](https://zapsmtp.com/docs/template-library/upload-template-asset/): POST
- [Delete an image](https://zapsmtp.com/docs/template-library/delete-template-asset/): DELETE
- [Create a countdown timer](https://zapsmtp.com/docs/template-library/create-template-timer/): POST
