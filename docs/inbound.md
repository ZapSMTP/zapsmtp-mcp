# Inbound setup API

> Inbound addresses on managed or own domains, routing rules and stats.

Source: https://zapsmtp.com/docs/inbound/

Get an instant managed address or receive on your own domain, then route messages by recipient, sender or header to a webhook, storage or rejection.

- [List inbound domains](https://zapsmtp.com/docs/inbound/list-inbound-domains/): GET
- [Add an inbound domain](https://zapsmtp.com/docs/inbound/create-inbound-domain/): POST
- [Retrieve an inbound domain](https://zapsmtp.com/docs/inbound/get-inbound-domain/): GET
- [Update an inbound domain](https://zapsmtp.com/docs/inbound/update-inbound-domain/): PATCH
- [Verify MX records](https://zapsmtp.com/docs/inbound/verify-inbound-domain/): POST
- [Delete an inbound domain](https://zapsmtp.com/docs/inbound/delete-inbound-domain/): DELETE
- [List routes](https://zapsmtp.com/docs/inbound/list-routes/): GET
- [Create a route](https://zapsmtp.com/docs/inbound/create-route/): POST
- [Retrieve a route](https://zapsmtp.com/docs/inbound/get-route/): GET
- [Update a route](https://zapsmtp.com/docs/inbound/update-route/): PATCH
- [Delete a route](https://zapsmtp.com/docs/inbound/delete-route/): DELETE
- [List forward destinations](https://zapsmtp.com/docs/inbound/list-forward-destinations/): GET
- [Add a forward destination](https://zapsmtp.com/docs/inbound/create-forward-destination/): POST
- [Resend the confirmation](https://zapsmtp.com/docs/inbound/resend-forward-confirmation/): POST
- [Remove a forward destination](https://zapsmtp.com/docs/inbound/delete-forward-destination/): DELETE
- [Inbound stats](https://zapsmtp.com/docs/inbound/inbound-stats/): GET
